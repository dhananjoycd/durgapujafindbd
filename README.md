# শারদীয়া

A Bengali-first Durga Puja greeting-card editor and, in later milestones, a community Puja Finder.

## Getting started

```bash
npm install
npm run dev
```

The editor is designed to work in the browser without login or an AI service. Choose one of three distinct compositions, add a photo, edit text on the card, and export a 2x PNG.
